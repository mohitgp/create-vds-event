# create-vds-event
This repo automates creation of events on the Vaidic Dharma Sansthan web portal using the chrome extension UI.Vision.

UI.Vision Extension
  https://ui.vision/
  chrome://extensions/?id=gcbalfbdmfieckjlnblleoemohcganoc

Setup Steps
1. Install Chrome browser if not already installed.
2. Install UI.Vision Extension in the Chrome browser.
3. Insert data to for the event in the CreatePrivateRPEventData.csv
4. Play macro. Macro will fill all the details in the create event form.
5. Verify data manually and then click Submit Request.
